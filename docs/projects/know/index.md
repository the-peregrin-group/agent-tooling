# know: the Knowledge Skills

## Overview

The Knowledge Skills teach knowledge rather than direct a procedure (the
**Knowledge Skill** entry in [LEXICON.md](../../../LEXICON.md) defines the
family). Each is named `know-<topic>`, and its description gives a concise
distillation of what it teaches, so the knowledge reaches every session from
the Skill listing before anything is loaded; the body adds depth and how to
apply it. Other Skills point at a Knowledge Skill rather than restating its
knowledge, so the text lives in one place.

`know-unattended` is the first. It holds the operating rule for the
lexicon's Attended session and Unattended session: a session is unattended
only when its prompt declares that no person will answer, and an act that
would need a person's approval becomes a proposal in the final report.
