# Architecture decision records

Design decisions for this repo, one file per decision, named
`NNNN-short-title.md`. Numbering starts at 0001 in this repo.

Each ADR takes the conventional shape: the context that forced a decision, the
decision itself, and its consequences, including the alternatives rejected and
why. Record a decision only when it is hard to reverse, would surprise a reader
without context, and came out of a real trade-off.
