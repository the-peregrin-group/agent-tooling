# Alternatives Considered and Tradeoffs

Optional section for ADR. Follow guidance in `./writing-adrs.md` to see if warranted.

## Why track alternatives considered?

Again, the goal is to preserve context on _why_ a decision was made.

Alternatives are worth tracking only if they help us avoid relitigating the decision or falling into the same trap.

Do not bother tracking obviously-bad alternatives. If there is no interesting rejection rationale, it is not worth remembering.

## Template

```md
{added at the end of the ADR document}

## Alternatives Considered

### {Name of option N}

**Description:** {concise description of alternative approach}
**Rejection rationale:** {concise description of rationale for NOT choosing this approach, esp. focusing on engineering trade-offs}

{repeat ### sections as needed, one per option}
```
