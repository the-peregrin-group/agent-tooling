# Brain Breadcrumb

This repository is delegated work tracked in a private, local-only knowledge
base (the "brain"). This file declares that link — it is the only
brain-related artifact committed to this repository (brain ADR 0022).

- **Origin** (`origin`): this repository's identity in the brain's stream
  inboxes — the leaf name of its brain front door (brain ADR 0019). Declared
  here, never derived from the repo name.
- **Front door** (`front-door`): the brain-relative path where this project's
  truth lives. Committed pointers into the brain go through the front door
  and never deeper (brain ADR 0007).

Agents: this machine grants your session brain access — front-door read,
own-inbox stream writes, the capture-commit push — via the untracked
`.claude/settings.local.json`, generated by the `init-project-repo` skill.
If those grants are missing, this repository has no brain write path; ask
the user to re-run `init-project-repo` rather than improvising.

**Mailbox:** coordination with the brain travels as Messages in this
project's Mailbox, the `mailbox/` directory beside the front door
(brain ADR 0008). A Message carries coordination only; a real work item
goes on its target's task surface instead. Each Message is one new
Markdown file, named `YYYY-MM-DD-<slug>.md`, and is never edited once
sent: correct it with a new Message. Its YAML frontmatter holds `privacy`
(the front door's class or stricter), `date`, `from`, `to`, `subject`, and
optionally `re` (the Message it answers), followed by a freeform body.

- **Send** (repo→brain): write the file into `mailbox/to-brain/`, then run
  the capture commit, `brain-capture-commit.sh agent-tooling`.
- **Receive** (brain→repo): read `mailbox/to-repo/`; once a Message is acted
  on, mark it consumed with
  `brain-capture-commit.sh agent-tooling consume <file>`, which moves it to
  `mailbox/processed/`.

Both run the installed script at the exact path your allow rules in
`.claude/settings.local.json` pin (brain ADR 0034).
